# ⚙️ پنل مدیریت فاکس کوین — فاز ۳

پنل مدیریت فاکس کوین، بخش باقی‌مانده پروژه است که در این نسخه کامل شد:
آمار، تنظیمات، **فاکس شاپ**، کاربران، قیمت پلن‌ها، دفتر کل و **متن‌ها** —
همه با دکمه.

## فایل‌ها

| فایل | نقش |
|---|---|
| `foxcoin.js` | هسته (نسخه ۱.۵.۰): محصول + مدیریت + فروشگاه + جوایز + **متن‌های سفارشی** |
| `foxcoin-ui.js` | رابط کاربری کاربر عادی (۱.۳.۰): جوایز زنده + **متن‌های سفارشی**، بدون بخش دعوت |
| `foxcoin-admin.js` | **پنل مدیریت (۱.۴.۰): فاکس شاپ + دست بازتر + جوایز + متن‌ها** |
| `patch-foxcoin-admin.py` | وصله اتصال پنل به `bot.js` |
| `patch-foxcoin-texts.py` | وصله دریافت متن از ادمین در `bot.js` (برای بخش متن‌ها) |
| `move-foxcoin-admin.py` | انتقال دکمه پنل به منوی «مدیریت ارشد» ربات |
| `upgrade-foxcoin.py` | ارتقای هسته قدیمی سرور به نسخه کامل (نسخه ۲.۳) |
| `patch-foxcoin.py` | وصله فاز ۲ (بدون تغییر) |

## چه کسی ادمین است؟

درِ واقعی پنل در خود ماژول بسته می‌شود — نه با مخفی‌بودن دکمه.
اگر ادمین نباشی، فقط پیام «⛔ این بخش فقط برای مدیریت است» می‌گیری.

دو راه تعیین ادمین:

1. **متغیر محیطی** (پیشنهادی):
   ```bash
   # در فایل سرویس ربات
   Environment=FOXCOIN_ADMINS=123456789,987654321
   ```
2. **کانفیگ ربات**: `config.admins` (آرایه)، یا `config.adminIds`،
   یا `config.ownerId`، یا `config.owner`.

> اگر هیچ‌کدام تنظیم نشود، پنل برای همه قفل است. قفل پیش‌فرض
> امن‌تر از باز پیش‌فرض است.

## دسترسی به پنل

دکمه «⚙️ مدیریت فاکس کوین» در **منوی مدیریت ارشد ربات** است (بعد از
ردیف «راهنمای اتصال گروه»). منوی ارشد فقط برای ادمین‌های ربات باز
می‌شود؛ درِ واقعی پنل همچنان با `FOXCOIN_ADMINS` یا `config.admins`
کنترل می‌شود.

> اگر دکمه هنوز در منوی اصلی ربات است (نصب قبلی)، اسکریپت انتقال
> را اجرا کن:
> ```bash
> python3 move-foxcoin-admin.py --apply
> systemctl restart foxteam-bot
> ```

## 🛍 مدیریت فاکس شاپ

صفحه «فاکس شاپ» در پنل:

- **⛔ بستن / ✅ باز کردن فروشگاه** — با یک دکمه. وقتی بسته است،
  کاربر عادی در فروشگاه فقط پیام «فروشگاه بسته است» می‌بیند و
  خریدش حتی با زدن دکمه تأیید هم متوقف است. موجودی همه محفوظ است.
- **➕ محصول جدید** — ساخت مرحله‌ای بدون تایپ متن:
  ۱. انتخاب دسته (حجمی / زمانی)
  ۲. انتخاب پلن از **لیست زنده پلن‌های ربات**
  ۳. تنظیم حجم، مدت و قیمت با دکمه‌های +/−
  ۴. ثبت — برچسب خودکار از نام پلن ساخته می‌شود
- روی هر محصول بزنید تا صفحه جزئیات باز شود:
  - **🔁 نام خودکار** — بازسازی نام از نام پلن زنده + حجم + مدت
  - **🛰 تغییر پلن** — انتخاب پلن جدید از لیست زنده همان دسته
  - **🔄 تغییر دسته** — حجمی ↔ زمانی (بعدش پلن جدید انتخاب می‌شود)
  - ویرایش حجم، مدت، قیمت کوینی، فعال/غیرفعال، حذف با تأیید

تنظیم مربوطه: `shopEnabled` (در تنظیمات پنل هم قابل تغییر است؛
از خط فرمان: `node foxcoin.js set shopEnabled false`).

## 🎁 جوایز فعالیت — کوین دلخواه برای هر کار

از «⚙️ تنظیمات» → «🎁 جوایز فعالیت»:

| فعالیت | کلید | معنی |
|---|---|---|
| ثبت‌نام در ربات | `signup` | یک‌بار جایزه ثبت‌نام |
| جوین کانال/گروه | `join` | یک‌بار جایزه جوین |
| دعوت دوستان | `referral` | پس از خرید دوست دعوت‌شده |
| انجام ماموریت | `mission` | هر ماموریت |

- روی هر آیتم بزنید → با دکمه‌های +/− مقدار را به **هر عدد دلخواه**
  برسانید (صفر = آن فعالیت جایزه ندارد). اعمال فوری، بدون تایپ.
- «↩️ پیش‌فرض» مقدار را به حالت اولیه برمی‌گرداند.
- **فعالیت سفارشی** (مثلاً بازدید روزانه) از خط فرمان ساخته می‌شود و
  بعد در همین صفحه با دکمه قابل ویرایش و حذف است:
  ```bash
  node foxcoin.js reward-add daily 7     # افزودن فعالیت «daily» با جایزه ۷
  node foxcoin.js reward daily 12        # تغییر مقدار
  node foxcoin.js rewards                # دیدن همه
  node foxcoin.js reward-del daily       # حذف
  ```
- اعطای واقعی جایزه به کاربر در کد ربات با `coin.grantReward(uid, 'join')`
  انجام می‌شود (یک‌بار برای هر کاربر؛ در گردش حساب با نام فارسی ثبت می‌شود).

> بخش «👥 دعوت دوستان» از منوی کاربر حذف شد — همه‌چیز روی محور
> فاکس کوین می‌چرخد. مقدار جایزه دعوت همچنان از همین صفحه قابل تنظیم است.

## 📝 متن‌ها — متن دلخواه برای هر بخش

از «📝 متن‌ها» در منوی مدیریت، متن‌هایی که کاربر در بخش‌های فاکس کوین
می‌بیند را بدون کدنویسی عوض می‌کنی:

| متن | کلید | پیش‌فرض |
|---|---|---|
| متن تشویقی منوی کوین | `menu_note` | «🎁 با فعالیت در ربات کوین جمع کنید و...» |
| متن «فاکس کوین چیست» | `guide_what` | توضیح امتیاز داخلی |
| متن قوانین | `guide_rules` | سه قانون؛ جای‌نگهدار `{dailyCap}` خودش با سقف روزانه واقعی پر می‌شود |
| سطر پایانی راهنما | `guide_footer` | «همه رویدادها در گردش حساب ثبت می‌شود.» |
| عنوان بخش ثبت‌نام | `earn_signup` | «ثبت‌نام در ربات» |
| عنوان بخش جوین | `earn_join` | «جوین کانال/گروه» |
| عنوان بخش خرید | `earn_purchase` | «خرید سرویس» |
| عنوان بخش ماموریت | `earn_mission` | «انجام ماموریت‌ها» |
| عنوان بخش دعوت دوستان | `earn_referral` | «خرید دوستان دعوت‌شده» |

چطور ویرایش می‌شود:

1. «📝 متن‌ها» → روی متنی که می‌خواهی عوض کنی بزن
2. ربات می‌گوید «متن جدید را بفرست» — همان را بفرست
3. ذخیره می‌شود و از آن لحظه در منو/راهنما همان دیده می‌شود

- 🟢 یعنی متن سفارشی است؛ «↩️ پیش‌فرض» آن را به حالت اولیه برمی‌گرداند.
- «🔙 انصراف» بدون ذخیره خارج می‌شود.
- کاراکتر `<` و `>` مجاز نیست (متن‌های HTML‌دار پیام را خراب می‌کنند).
- جای‌نگهدار `{dailyCap}` در متن قوانین با سقف روزانه واقعی پر می‌شود.
- اگر هوک bot.js نصب نباشد، متن‌ها از خط فرمان هم قابل ویرایش‌اند:
  ```bash
  node foxcoin.js texts                      # دیدن همه متن‌ها
  node foxcoin.js text earn_join "عضو کانال شدن"   # تغییر
  node foxcoin.js text-reset earn_join       # برگشت به پیش‌فرض
  ```

برای فعال‌شدن دریافت متن از داخل پنل (قدم ۲)، وصله هوک را نصب کن:

```bash
cd /root/foxteam-bot
curl -fsSL -o patch-foxcoin-texts.py https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/patch-foxcoin-texts.py
python3 patch-foxcoin-texts.py          # نمایش برنامه (بدون تغییر)
python3 patch-foxcoin-texts.py --apply  # اعمال واقعی
systemctl restart foxteam-bot
```

این وصله همان الگوی «مدیریت متن‌ها» خود ربات است: دو هوک کوچک در
`bot.js` (دریافت پیام ادمین + ثبت حالت) با بکاپ و `node --check` و
برگشت خودکار. اگر bot.js سرور با الگوی شناخته‌شده فرق داشته باشد،
اسکریپت بدون تغییر چیزی گزارش می‌دهد و متن‌ها همچنان از خط فرمان
قابل ویرایش‌اند.

## 🎯 دست بازتر — کاربران

- **👥 همه کاربران** — از صفحه «کاربران»؛ لیست کامل همه کاربرانی که
  تاکنون رویداد یا موجودی داشته‌اند، با صفحه‌بندی (۱۰ تایی) — دیگر
  فقط به دارندگان برتر و کاربران اخیر محدود نیستی.
- **🎯 تنظیم دقیق موجودی** — در صفحه هر کاربر؛ موجودی را دقیقاً روی
  هر عددی می‌گذاری (نه فقط +/−). اختلاف به‌صورت رویداد ادمین ثبت می‌شود.
- **📌 دلیل برای هر تغییر** — در افزودن/کسر/تنظیم دقیق، دلیل را از
  فهرست انتخاب می‌کنی: 🎁 هدیه، 🏆 جایزه، 🔧 جبران خطا، ⚖️ تصحیح
  موجودی، 📝 سایر. دلیل در گردش حساب کاربر و دفتر کل ثبت می‌شود.

قواعد ایمنی:

- هر تغییر موجودی یک رویداد «اصلاح ادمین» در دفتر کل ثبت می‌شود
  و در گردش حساب کاربر دیده می‌شود.
- کسر بیش از موجودی ممکن نیست.
- حذف محصول و پرداخت/کسر کوین قفل ضد دوبار-کلیک دارند.
- دکمه‌های +/− همان لحظه اعمال می‌شوند؛ هیچ حالتی در حافظه نمی‌ماند
  (بعد از ری‌استارت ربات هم صفحه‌ها درست‌اند).

## به‌روزرسانی سرور به نسخه فاکس شاپ

اگر پنل مدیریت قبلاً نصب است، فقط سه فایل را جایگزین کن و ری‌استارت کن
(وصله bot.js دست نمی‌خورد):

```bash
cd /root/foxteam-bot
curl -fsSL -o foxcoin.js       https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/foxcoin.js
curl -fsSL -o foxcoin-ui.js    https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/foxcoin-ui.js
curl -fsSL -o foxcoin-admin.js https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/foxcoin-admin.js

node foxcoin.js selftest | tail -3
node foxcoin-ui.js | tail -3
node foxcoin-admin.js | tail -3
systemctl restart foxteam-bot
```

## نصب اولیه روی سرور

```bash
cd /root/foxteam-bot

# ۱) فایل‌های جدید را جایگزین/اضافه کن:
#    foxcoin.js (نسخه جدید)، foxcoin-ui.js، foxcoin-admin.js

# ۲) اگر هسته سرور هنوز نسخه قدیمی است:
python3 upgrade-foxcoin.py --apply

# ۳) تست:
node foxcoin.js selftest | tail -3
node foxcoin-ui.js | tail -3
node foxcoin-admin.js | tail -3

# ۴) اتصال پنل به ربات (بعد از وصله فاز ۲):
python3 patch-foxcoin-admin.py --apply

# ۴-ب) (برای ویرایش متن‌ها از داخل پنل) هوک دریافت متن:
python3 patch-foxcoin-texts.py --apply

# ۵) ادمین‌ها را تعیین کن (یا در کانفیگ ربات):
#    Environment=FOXCOIN_ADMINS=<شناسه عددی تو>

# ۶) (اختیاری) انتقال دکمه به منوی مدیریت ارشد:
python3 move-foxcoin-admin.py --apply

# ۷) ری‌استارت:
systemctl restart foxteam-bot
```

اگر چیزی خراب شد:

```bash
python3 patch-foxcoin-admin.py --revert     # برگرداندن bot.js
cp -a foxcoin.js.bak-* foxcoin.js          # برگرداندن هسته
```

## خط فرمان (کارهای پیشرفته)

```bash
node foxcoin.js products                          # فهرست محصولات
node foxcoin.js product-add '{"id":"P1","label":"سی گیگ","planId":"44trir5v","cat":"volume","gb":30,"days":30,"coins":100}'
node foxcoin.js product-del P1                    # حذف محصول
node foxcoin.js price <plan> <coins>              # قیمت کوینی پلن
node foxcoin.js prices                            # همه قیمت‌ها
node foxcoin.js top 10                            # دارندگان برتر
node foxcoin.js recent 5                          # کاربران اخیر
node foxcoin.js ledger 20                         # دفتر کل
node foxcoin.js grant <uid> <amount> <دلیل>       # افزودن/کسر کوین
node foxcoin.js set reportChatId <گروه>           # گروه گزارش
node foxcoin.js texts                            # دیدن همه متن‌ها
node foxcoin.js text <کلید> <متن>                # تغییر متن
node foxcoin.js text-reset <کلید>                # برگشت به پیش‌فرض
```
