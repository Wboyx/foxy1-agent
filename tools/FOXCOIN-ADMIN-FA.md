## چه کسی ادمین است؟

درِ واقعی پنل در خود ماژول بسته می‌شود — نه با مخفی‌بودن دکمه.
اگر ادمین نباشی، فقط پیام «⛔ این بخش فقط برای مدیریت است» می‌گیری.

دو راه تعیین ادمین:

1. **متغیر محیطی** (پیشنهادی):
   ```bash
   # در فایل سرویس ربات
   Environment=FOXCOIN_ADMINS=123456789,987654321
   ```
2. **کانفیگ ربات**: `config.admins` (آرایه)، یا `config.adminIds`،
   یا `config.ownerId`، یا `config.owner`.

> اگر هیچ‌کدام تنظیم نشود، پنل برای همه قفل است. قفل پیش‌فرض
> امن‌تر از باز پیش‌فرض است.

## دسترسی به پنل

دکمه «⚙️ مدیریت فاکس کوین» در **منوی مدیریت ارشد ربات** است (بعد از
ردیف «راهنمای اتصال گروه»). منوی ارشد فقط برای ادمین‌های ربات باز
می‌شود؛ درِ واقعی پنل همچنان با `FOXCOIN_ADMINS` یا `config.admins`
کنترل می‌شود.

> اگر دکمه هنوز در منوی اصلی ربات است (نصب قبلی)، اسکریپت انتقال
> را اجرا کن:

> python3 move-foxcoin-admin.py --apply
> systemctl restart foxteam-bot
> ```

## 🛍 مدیریت فاکس شاپ

صفحه «فاکس شاپ» در پنل:

- **⛔ بستن / ✅ باز کردن فروشگاه** — با یک دکمه. وقتی بسته است،
  کاربر عادی در فروشگاه فقط پیام «فروشگاه بسته است» می‌بیند و
  خریدش حتی با زدن دکمه تأیید هم متوقف است. موجودی همه محفوظ است.
- **➕ محصول جدید** — ساخت مرحله‌ای بدون تایپ متن:
  ۱. انتخاب دسته (حجمی / زمانی)
  ۲. انتخاب پلن از **لیست زنده پلن‌های ربات**
  ۳. تنظیم حجم، مدت و قیمت با دکمه‌های +/−
  ۴. ثبت — برچسب خودکار از نام پلن ساخته می‌شود
- روی هر محصول بزنید تا صفحه جزئیات باز شود:
  - **🔁 نام خودکار** — بازسازی نام از نام پلن زنده + حجم + مدت
  - **🛰 تغییر پلن** — انتخاب پلن جدید از لیست زنده همان دسته
  - **🔄 تغییر دسته** — حجمی ↔ زمانی (بعدش پلن جدید انتخاب می‌شود)
  - ویرایش حجم، مدت، قیمت کوینی، فعال/غیرفعال، حذف با تأیید

تنظیم مربوطه: `shopEnabled` (در تنظیمات پنل هم قابل تغییر است؛
از خط فرمان: `node foxcoin.js set shopEnabled false`).

## ⚠️ اگر «محصول جدید» بن‌بست می‌خورد

نشانه‌ها:

- در پنل، «➕ محصول جدید» → انتخاب دسته → پیام
  «❌ لیست پلن‌های ربات در دسترس پنل نیست»
- کاربر در فروشگاه دکمه تأیید را می‌زند و هیچ اتفاقی نمی‌افتد

علت: ماژول‌های کوین دو تابع را از خود ربات می‌گیرند —
`getPlans` (لیست پلن‌ها) و `deliverService` (ساخت سرویس). وصله‌های
فاز ۲ و ۳ این دو را در `ctx` نمی‌گذاشتند، پس پنل هیچ‌وقت پلنی
نمی‌دید و خرید کاربر با `TypeError` می‌مرد.

درمان — یک وصله:

```bash
cd /root/foxteam-bot
curl -fsSL -o patch-foxcoin-plans.py https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/patch-foxcoin-plans.py
python3 patch-foxcoin-plans.py          # نمایش برنامه + توابع کشف‌شده
python3 patch-foxcoin-plans.py --apply  # اعمال واقعی
systemctl restart foxteam-bot
```

اسکریپت نام توابع را خودش از `bot.js` پیدا می‌کند. اگر نام‌ها در
ربات تو فرق دارد، خودش نامزدهای مشابه را فهرست می‌کند و می‌توانی
دستی بدهی:

```bash
FOXCOIN_GETPLANS=loadPlans FOXCOIN_DELIVER=createService \
    python3 patch-foxcoin-plans.py --apply
```

برگشت: `python3 patch-foxcoin-plans.py --revert`

### راه دوم: افزودن دستی

اگر وصله نخورد، پنل دیگر بن‌بست نیست: دکمه **«✍️ افزودن دستی»**
می‌آید، شناسه پلن را متنی می‌فرستی و بقیه مراحل مثل قبل با دکمه
پیش می‌رود. (نیازمند هوک `patch-foxcoin-texts.py`.)

یا از خط فرمان:

```bash
node foxcoin.js product-add '{"id":"P1","label":"سی گیگ","planId":"44trir5v","cat":"volume","gb":30,"days":30,"coins":100}'
```

## 🪜 پلکان خرید — جایزه بر اساس شماره خرید

«خرید اول ۱۰۰ کوین، دوم ۵۰، سوم ۲۵، بقیه ۱۰» — بدون کدنویسی.

**از پنل:** «🎁 جوایز فعالیت» → «🪜 پلکان خرید»

- **✅ روشن کردن** — با دو پله پیش‌فرض (۵۰ و ۳۰) شروع می‌شود
- هر پله ردیف +/− خودش را دارد
- **➕ افزودن پله** / **🗑 حذف آخری**
- **بقیه خریدها** — جایزه خریدهای بعد از آخرین پله

وقتی پلکان روشن است، «خرید سرویس» و «اولین خرید» از فهرست جوایز
کنار می‌روند — چون پله اول خودش همان جایزه اولین خرید است. با
خاموش‌کردن پلکان، همه‌چیز به حالت قبل برمی‌گردد.

شماره خرید از **دفتر کل** شمرده می‌شود، نه از شمارنده جدا. یعنی
اگر ادمین رویدادی را دستی اصلاح کند، شمارش هم خودش درست می‌ماند.

از خط فرمان:

```bash
node foxcoin.js tiers                    # دیدن پلکان
node foxcoin.js tiers-set '100,50,25' 10 # پله‌ها + بقیه
node foxcoin.js tiers-test 3             # جایزه سومین خرید چقدر است
node foxcoin.js tiers-off                # خاموش
node foxcoin.js purchase-count <uid>     # چند خرید کرده
```

## 🧮 فرمول قیمت — به‌جای تنظیم تک‌تک

منوی قدیمی «💵 قیمت پلن‌ها» **حذف شد**. آن منو روی خرید هیچ اثری
نداشت: خرید همیشه از `product.coins` می‌خواند، نه از `coinPrices`.
هرچه آنجا تنظیم می‌کردی بی‌اثر بود — علت «حساب‌کتاب درست در نمیاد».

جایش «🧮 فرمول قیمت» آمده که برای **هر دسته جدا** فرمول دارد:

| دسته | فرمول |
|---|---|
| 🧬 حجمی | `هر گیگ × گیگ + هر روز × روز + پایه` |
| ♾ نامحدود | `هر روز × روز + پایه` (حجم ندارد) |

پیش‌فرض‌ها: حجمی ۳ کوین/گیگ — نامحدود ۵۰ پایه + ۲ کوین/روز.

نحوه کار:

1. «🧮 فرمول قیمت» → دسته را انتخاب کن
2. با +/− عددها را تنظیم کن — پایین صفحه **مثال زنده** می‌بینی
3. برگرد و «👁 پیش‌نمایش» بزن تا ببینی چه قیمتی عوض می‌شود
4. «✅ اعمال» → همه محصولات آن دسته یکجا قیمت می‌گیرند

**قیمت دستی:** اگر محصولی را دستی قیمت بگذاری، فرمول دیگر به آن
دست نمی‌زند. برای برگرداندنش به حالت خودکار:

```bash
node foxcoin.js product-auto <شناسه محصول>
```

از خط فرمان:

```bash
node foxcoin.js pricing                                  # دیدن هر دو فرمول
node foxcoin.js pricing-set volume '{"perGb":4,"base":10}'
node foxcoin.js pricing-set unlimited '{"perDay":3}'
node foxcoin.js pricing-preview                          # چه عوض می‌شود
node foxcoin.js pricing-apply                            # اعمال
node foxcoin.js pricing-apply volume force               # حتی دستی‌ها
node foxcoin.js product-manual P1 500                    # قیمت دستی
node foxcoin.js pricing-reset volume                     # پیش‌فرض
```

## ♾ دسته نامحدود

نسخه‌های قبلی دو دسته فرض می‌کردند: `volume` و `days`. ولی ربات
واقعی دسته‌ای به نام `days` **ندارد** — دسته‌هایش `volume` و
`unlimited` هستند. برای همین پلن‌های نامحدود هیچ‌وقت در پنل فهرست
نمی‌شدند.

حالا:

- «➕ محصول جدید» دو دکمه دارد: **♾ نامحدود** و **🧬 حجمی**
- برای نامحدود، مرحله حجم **رد می‌شود** (حجم ندارد)
- در فروشگاه کاربر، محصولات **گروه‌بندی شده** نمایش داده می‌شوند
- صفحه تأیید خرید برای نامحدود «♾ بدون محدودیت» نشان می‌دهد،
  نه «۰ گیگابایت»

محصولات قدیمی که با دسته `days` ساخته شده‌اند خودکار به `unlimited`
نگاشت می‌شوند؛ نیازی به کار دستی نیست.

## 🎁 جوایز فعالیت — موتور پیشرفته

از «⚙️ تنظیمات» → «🎁 جوایز فعالیت»، برای **هر فعالیت** می‌توانی:

| گزینه | معنی |
|---|---|
| **💰 ثابت** | هر بار جایزه، N کوین |
| **📈 درصدی** | درصدی از مبلغ خرید + **سقف** هر جایزه |
| **🔢 نسبی** | هر X تومان خرید، ۱ کوین |
| **حداقل خرید** | زیر این مبلغ خرید، جایزه‌ای داده نمی‌شود |
| **🔁 همیشگی / 🔂 یک‌بار** | هر بار تکرار می‌شود یا فقط یک بار برای هر کاربر |
| **✅ فعال / ⛔ غیرفعال** | روشن/خاموش کردن آن فعالیت |

### فعالیت‌های آماده

| فعالیت | کلید | پیش‌فرض |
|---|---|---|
| ثبت‌نام در ربات | `signup` | ۵ کوین، یک‌بار |
| جوین کانال/گروه | `join` | ۱۰ کوین، یک‌بار |
| خرید سرویس (خود کاربر) | `purchase` | ۱۰ کوین، همیشگی |
| اولین خرید کاربر | `first_purchase` | ۲۰ کوین، یک‌بار (جایزه خوش‌آمدگویی) |
| دعوت دوستان (اولین خرید دعوت‌شده) | `referral` | ۱۰ کوین، یک‌بار |
| **خرید زیرمجموعه‌ها (هر بار)** | `ref_purchase` | ۵٪ از مبلغ خرید، سقف ۱۰۰ کوین |
| حضور روزانه | `daily` | ۵ کوین + پاداش زنجیره |
| انجام ماموریت | `mission` | ۳ کوین، یک‌بار |

### جایزه روزانه و زنجیره

دکمه «🎁 جایزه روزانه» در منوی کوین: هر روز یک بار کوین می‌دهد و
**هر روز پیاپی ۱۰٪ پاداش بیشتر** (تا ۲ برابر). قطع شدن یک روز،
زنجیره را صفر می‌کند.

### اتصال به خرید واقعی

با `patch-foxcoin-rewards.py`، جایزه خرید و پاداش اولین خرید به
**قیف مرکزی پرداخت** ربات (تابع `fulfillOrder`) وصل می‌شود:

```bash
cd /root/foxteam-bot
curl -fsSL -o patch-foxcoin-rewards.py https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/patch-foxcoin-rewards.py
python3 patch-foxcoin-rewards.py --apply
systemctl restart foxteam-bot
```

- وقتی زیرمجموعه‌ای خرید می‌کند: جایزه `ref_purchase` به دعوت‌کننده
  (درصدی/سقف) و جایزه `referral` یک‌بار به ازای اولین خرید او.
- همه در گردش حساب ثبت می‌شود: «خرید»، «جایزه اولین خرید»، «دعوت دوستان».

### خط فرمان (کارهای پیشرفته)

```bash
node foxcoin.js rewards                              # دیدن همه پیکربندی‌ها
node foxcoin.js reward join 25                       # ثابت: ۲۵ کوین
node foxcoin.js reward-mode ref_purchase percent     # حالت درصدی
node foxcoin.js reward-config ref_purchase '{"percent":7,"cap":200}'
node foxcoin.js reward-cap ref_purchase 150          # سقف
node foxcoin.js reward-min purchase 50000            # حداقل مبلغ خرید
node foxcoin.js reward-repeat purchase always        # همیشگی / once
node foxcoin.js reward-toggle daily                  # فعال/غیرفعال
node foxcoin.js reward-add visit 7                   # فعالیت سفارشی
node foxcoin.js reward-del visit                     # حذف فعالیت سفارشی
node foxcoin.js daily <userId>                       # تست جایزه روزانه
node foxcoin.js purchase <userId> <مبلغ>             # تست جایزه خرید
node foxcoin.js ref-purchase <دعوت‌کننده> <دعوت‌شده> <مبلغ>
```

> بخش «👥 دعوت دوستان» از منوی کاربر حذف شد — همه‌چیز روی محور
> فاکس کوین می‌چرخد. جوایز دعوت و خرید زیرمجموعه‌ها از همین صفحه
> قابل تنظیم است.

| عنوان بخش خرید | `earn_purchase` | «خرید سرویس» |
| عنوان بخش ماموریت | `earn_mission` | «انجام ماموریت‌ها» |
| عنوان بخش دعوت دوستان | `earn_referral` | «خرید دوستان دعوت‌شده» |

چطور ویرایش می‌شود:

1. «📝 متن‌ها» → روی متنی که می‌خواهی عوض کنی بزن
2. ربات می‌گوید «متن جدید را بفرست» — همان را بفرست
3. ذخیره می‌شود و از آن لحظه در منو/راهنما همان دیده می‌شود

- 🟢 یعنی متن سفارشی است؛ «↩️ پیش‌فرض» آن را به حالت اولیه برمی‌گرداند.
- «🔙 انصراف» بدون ذخیره خارج می‌شود.
- کاراکتر `<` و `>` مجاز نیست (متن‌های HTML‌دار پیام را خراب می‌کنند).
- جای‌نگهدار `{dailyCap}` در متن قوانین با سقف روزانه واقعی پر می‌شود.
- اگر هوک bot.js نصب نباشد، متن‌ها از خط فرمان هم قابل ویرایش‌اند:
  ```bash
  node foxcoin.js texts                      # دیدن همه متن‌ها
  node foxcoin.js text earn_join "عضو کانال شدن"   # تغییر
  node foxcoin.js text-reset earn_join       # برگشت به پیش‌فرض
  ```

برای فعال‌شدن دریافت متن از داخل پنل (قدم ۲)، وصله هوک را نصب کن:

```bash

curl -fsSL -o patch-foxcoin-texts.py https://raw.githubusercontent.com/Wboyx/foxy1-agent/main/tools/patch-foxcoin-texts.py

```

این وصله همان الگوی «مدیریت متن‌ها» خود ربات است: دو هوک کوچک در
`bot.js` (دریافت پیام ادمین + ثبت حالت) با بکاپ و `node --check` و
برگشت خودکار. اگر bot.js سرور با الگوی شناخته‌شده فرق داشته باشد،
اسکریپت بدون تغییر چیزی گزارش می‌دهد و متن‌ها همچنان از خط فرمان
قابل ویرایش‌اند.

## 🎯 دست بازتر — کاربران

- **👥 همه کاربران** — از صفحه «کاربران»؛ لیست کامل همه کاربرانی که
  تاکنون رویداد یا موجودی داشته‌اند، با صفحه‌بندی (۱۰ تایی) — دیگر
  فقط به دارندگان برتر و کاربران اخیر محدود نیستی.
- **🎯 تنظیم دقیق موجودی** — در صفحه هر کاربر؛ موجودی را دقیقاً روی
  هر عددی می‌گذاری (نه فقط +/−). اختلاف به‌صورت رویداد ادمین ثبت می‌شود.
- **📌 دلیل برای هر تغییر** — در افزودن/کسر/تنظیم دقیق، دلیل را از
  فهرست انتخاب می‌کنی: 🎁 هدیه، 🏆 جایزه، 🔧 جبران خطا، ⚖️ تصحیح
  موجودی، 📝 سایر. دلیل در گردش حساب کاربر و دفتر کل ثبت می‌شود.

قواعد ایمنی:

- هر تغییر موجودی یک رویداد «اصلاح ادمین» در دفتر کل ثبت می‌شود
  و در گردش حساب کاربر دیده می‌شود.
- کسر بیش از موجودی ممکن نیست.
- حذف محصول و پرداخت/کسر کوین قفل ضد دوبار-کلیک دارند.
- دکمه‌های +/− همان لحظه اعمال می‌شوند؛ هیچ حالتی در حافظه نمی‌ماند
  (بعد از ری‌استارت ربات هم صفحه‌ها درست‌اند).

## 🎁 مرکز جوایز

از منوی اصلی پنل، دکمه **🎁 مرکز جوایز**. هرچه به جایزه مربوط است یکجاست:
هدیه خوش‌آمد، پلکان خرید، ماموریت‌ها، سقف روزانه و فهرست کامل جوایز فعالیت.

> پیش از این، جوایز زیر «تنظیمات» و پلکان زیر «جوایز» بود؛ سه کلیک عمق داشت
> و عملاً دیده نمی‌شد. حالا یک کلیک است.

## 🎯 ماموریت‌ها

**مرکز جوایز ← 🎯 ماموریت‌ها**

ماموریت یعنی کاری که کاربر انجام می‌دهد و کوین می‌گیرد. کاربر آن را در
«🎯 ماموریت‌ها»ی ربات می‌بیند، همراه نوار پیشرفت، و وقتی شرط کامل شد خودش
دکمهٔ دریافت را می‌زند.

### ساخت ماموریت

**➕ ماموریت جدید** ← یکی از الگوهای آماده را بزن. بدون تایپ ساخته می‌شود و
بعد جایزه، شرط و عنوانش را با دکمه تنظیم می‌کنی:

| الگو | نوع | شرط | جایزهٔ اولیه |
|---|---|---|---|
| اولین خرید | خرید | ۱ خرید | ۲۵ |
| سه خرید | خرید | ۳ خرید | ۵۰ |
| سه روز پیاپی | روزانه | ۳ روز | ۱۵ |
| هفت روز پیاپی | روزانه | ۷ روز | ۴۰ |
| رسیدن به ۱۰۰ کوین | موجودی | ۱۰۰ | ۲۰ |
| ماموریت دستی | دستی | — | ۱۰ |

### چهار نوع ماموریت

- **✋ دستی** — شرطی ندارد؛ هر کاربر می‌تواند یک‌بار بگیرد. برای هدیه‌های
  مناسبتی خوب است.
- **🛒 خرید** — بعد از N خرید باز می‌شود.
- **💰 موجودی** — وقتی موجودی کاربر به N کوین برسد.
- **📅 روزانه** — با N روز پیاپی مراجعه (از همان زنجیرهٔ روزانه می‌خواند).

### تنظیم هر ماموریت

روی ماموریت بزن:

- **💎 جایزه** — کم/زیاد با ۱± و ۱۰±
- **🎯 شرط** — همان N (برای دستی نمایش داده نمی‌شود)
- **✏️ عنوان** — عنوان تازه را در چت می‌فرستی
- **🔂 یک‌بار / 🔁 همیشگی** — همیشگی یعنی کاربر هر بار می‌تواند بگیرد
- **⏸ غیرفعال** — از دید کاربر محو می‌شود، ولی پاک نمی‌شود
- **🗑 حذف** — با یک صفحهٔ تأیید

> جایزهٔ ماموریت هم مشمول **سقف روزانه** است.

## 🚦 سقف روزانه

**مرکز جوایز ← 🚦 سقف روزانه**

بیشترین کوینی که یک کاربر در یک روز می‌تواند بگیرد. دکمه‌های ۵۰±، ۱۰۰± و
۱۰۰۰±، به‌علاوهٔ **♾ بدون سقف** (یعنی صفر) و **↩️ پیش‌فرض ۲۰۰**.

خرید کاربر و اصلاح دستی ادمین از سقف معاف‌اند — سقف فقط جلوی جایزه‌گرفتن
بی‌حساب را می‌گیرد.

## ⬅️ دکمه بازگشت

دکمه بازگشت حالا **مسیر واقعی خودت** را دنبال می‌کند، نه یک مقصد ثابت.

قبلاً مقصد هر دکمه بازگشت در کد ثابت بود، پس هر صفحه فرض می‌کرد فقط از
یک راه باز می‌شود. وقتی «مرکز جوایز» راه دومی به پلکان خرید باز کرد،
بازگشتِ پلکان همچنان به والد قدیمی‌اش می‌رفت و تو سر از صفحه‌ای
درمی‌آوردی که اصلاً نرفته بودی.

حالا:

- از **مرکز جوایز** به پلکان بروی، بازگشت به **مرکز جوایز** برمی‌گردد
- از **تنظیمات ← جوایز** به پلکان بروی، بازگشت به **جوایز** برمی‌گردد

همان صفحه، دو مسیر، دو بازگشت درست. رفت‌وبرگشت پیاپی هم مسیر را باد
نمی‌کند و منوی اصلی همیشه ته مسیر است، پس بازگشت هیچ‌وقت بن‌بست نمی‌شود.

## 📝 متن‌ها (بازطراحی‌شده)

قبلاً هر سیزده متن در یک لیست بلند می‌آمدند و پیش‌نمایش هر کدام داخل
خودِ دکمه بود — دکمه‌ها دوخطی و درهم می‌شدند.

حالا دو دسته است:

| دسته | چه چیزی داخلش است |
|---|---|
| 📖 راهنما و منو | متن تشویقی منو، «کوین چیست»، قوانین، سطر پایانی |
| 💰 عنوان راه‌های کسب کوین | ثبت‌نام، هدیه خوش‌آمد، حضور روزانه، خرید، اولین خرید، ماموریت، جوین، دعوت دوستان، خرید زیرمجموعه |

داخل هر دسته، پیش‌نمایش‌ها در **متن پیام**‌اند و دکمه‌ها فقط نام کوتاه.
🟢 یعنی سفارشی، ⚪️ یعنی پیش‌فرض. کنار هر متن سفارشی یک ↩️ کوچک هست که
همان یکی را به پیش‌فرض برمی‌گرداند.

صفحه اول شمارش می‌دهد («۳ متن سفارشی») و اگر چیزی سفارشی باشد، دکمه
**↩️ برگرداندن همه به پیش‌فرض** ظاهر می‌شود.

در صفحه ویرایش، طول متن و خودِ متن پیش‌فرض هم نشان داده می‌شود تا
بدانی داری چه چیزی را عوض می‌کنی. برای متن قوانین، یادآوری می‌کند که
`{dailyCap}` را نگه داری.
